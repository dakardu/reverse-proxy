# Reverse Proxy

Configuración de NGINX como reverse proxy para entornos Docker.

## Tecnologías

- NGINX
- Docker
- Docker Compose

## Funcionalidades

- Reverse Proxy HTTP
- Balanceo de carga
- Integración con redes Docker
- Configuración centralizada mediante NGINX

## Ejecución

```bash
docker compose up -d --build
```
